# Catimer のコンセプトと想定機能

用語は [GLOSSARY.md](../GLOSSARY.md) に、後から覆しにくい決定は [docs/adr/](./adr/) にまとめている。この文書では、用語集の言葉をそのまま使う。

## コンセプト

Catimer は、ToDo とタスクごとのタイマーを組み合わせた、Mac のメニューバー常駐アプリ。メニューバーにはドット絵の猫と残り時間を出す。

- **決めた時間中、1つのタスクに集中しきる習慣を作る。** 一度始めた集中は、なかったことにはできない。途中で離席したり別のことを始めたりするなら、その集中は切り上げて終わったものとして扱う。
- **機能もUIも最小限にする。** 必要になったら自分で足したり直したりする。
- **自分専用で、長く使えるUXを優先する。** 業務の貸与PC（Mac）1台で使い、同期はしない。リポジトリはパブリックにし、技術ポートフォリオを兼ねる。
- **Macのリマインダーアプリを置き換える。** ToDo管理として使っている部分をCatimerで賄う。期日による通知（リマインド）はMVPに入れない。

### 自作する理由

- 既存のアプリには、タスクごとにタイマーを設定する機能や、繰り返すタスクを同じ設定で作り直す機能がない。
- Focus Todoは使い心地がよかったが、不要な機能が多く、貸与PCでの使用許可も降りなかった。

## MVPの機能

### タスク

- タスクが持つ項目は、タイトル、期日（任意）、優先度（高・中・低。デフォルトは中）、繰り返し設定（任意）、タイマー設定、済んだ集中回数、作業時間。メモ、タグ、プロジェクト、サブタスクは持たない。
- タスクは完了か削除で閉じる。タイマーを一度も使わずに完了してもよい。
- 繰り返し設定は「毎日」と「毎週（曜日を複数選べる）」の2種類で、期日のあるタスクにだけ付けられる。平日は、毎週の月〜金として表す。
- 繰り返し設定が付いたタスクを完了すると、タイトル、優先度、繰り返し設定、タイマー設定を引き継いだ次のタスクが生まれる。次の期日は、完了した日より後で、繰り返し設定に合う最初の日になる。済んだ集中回数と作業時間は0から数え直す。
  - 例：「毎週月曜日」のタスクを水曜日に完了したら、次の期日は来週の月曜日。
  - 例：「毎日」のタスクが3日間期限切れになったまま今日完了したら、次の期日は明日（期限切れだった間の分は作らない）。
- 完了しなかった繰り返しのタスクは、次のタスクを作らず、期限切れとして残る。削除したときも、次のタスクは作らない。
- 「今日」は午前0時に切り替わる。
- 完了したタスクは、その日のうちは取り消し線を付けて一覧に残し、日付が変わったら表示から外す。データは残し、MVPの後に作る振り返り機能で使う。削除したタスクは、作業時間の記録ごと消す。

### タイマー

- タイマー設定は、集中時間、短い休憩、長い休憩、集中回数の4項目で、どれも1以上（1分単位、1回単位）。デフォルトは、集中30分、短い休憩5分、長い休憩20分、集中回数3回（2時間のうち、集中が90分、休憩が30分）。
- 流れは次のとおり。

  ```
  待機 →（開始）→ 集中 →（自動）→ 休憩 → 待機 →（開始）→ 集中 → …
  ```

  - 集中が終わると、必ず自動で休憩が始まる。集中回数の区切り（デフォルトなら3回目、6回目……）の後は長い休憩、それ以外の後は短い休憩。
  - 休憩が終わると、必ず待機に戻る。次の集中は、毎回自分で開始する。
  - 集中回数を超えて開始しても、同じ区切りで次のまとまりが続く。
- 操作は「開始」と「切り上げ」の2つだけ。一時停止と停止はない。
  - 集中を切り上げると、その集中は終わったものとして済んだ集中回数に数え、休憩が始まる。作業時間には、切り上げた時点までの時間を足す。
  - 休憩を切り上げると、待機に戻る。
  - 1回ごとの集中について、やりきった集中か切り上げた集中かを記録する。MVPでは、記録を見る画面は作らない。
- 同時に動くタイマーは1つだけ。集中中と休憩中は、他のタスクの集中を開始できない。待機中なら、どのタスクでも開始できる。
- 済んだ集中回数はタスクが覚えておき、次に開始すると続きから数える。ウィンドウから手動でリセットできる（間違ったタスクで開始したときなど）。
- タイマーが動いているタスクを完了したり削除したりすると、タイマーはその時点で止まる。集中中だった場合は、その時点までの時間を作業時間に足す。
- 集中の途中でアプリを終了すると（Macの再起動も含む）、その時点で集中を終えたものとして扱う。
- スリープ中に集中の終了予定時刻を過ぎた場合は、終了予定時刻で集中が終わったものとして扱い、スリープから戻ったときに通知する。スリープや画面ロックを離席として自動で検知する機能は入れない。

### 通知と音

- 集中が終わったときと休憩が終わったときに、Macの通知を出し、音を鳴らす。音はアプリに同梱した中から、集中の終わり用と休憩の終わり用を、アプリ設定で別々に選ぶ。
- 期日による通知はしない。

### アプリ設定

- デフォルトのタイマー設定と、集中の終わりと休憩の終わりに鳴らす音を変えられる。音は試し聞きできる。
- 自動開始の切り替えや、グローバルショートカットの設定は持たない。

## UI

見た目は、ポップオーバーとウィンドウの両方をノート風にする（紙の質感、罫線、手書き風の取り消し線）。

### メニューバー

- ドット絵の猫と、集中中または休憩中の残り時間を出す。待機中は、残り時間を出さない。
- 猫の状態は4つ。MVPは静止画4枚で、アニメーションは実装が軽ければ入れる。

  | 状態 | 出すとき |
  |---|---|
  | 待機 | タイマーが待機のとき |
  | 集中 | 集中中 |
  | 休憩 | 休憩中 |
  | 完了 | タスクを完了した直後。数秒出した後、待機に戻る |

- 猫はメニューバーの中だけに出し、画面の中には出さない。

### ポップオーバー（メニューバーをクリックしたとき）

- 今日のタスクだけを出す。並び順は、期限切れ（期日の古い順）、今日のタスクの順。どちらも、その中で優先度の高い順、同じなら作った順に並べる。
- できる操作は、集中の開始、切り上げ、完了だけ。ウィンドウを開くボタンと、アプリを終了するボタンを置く。
- タスクの追加と、タイマー設定の変更はできない。

### ウィンドウ

- 表示を「今日」「予定（期日が明日以降）」「期日なし」から選べる。
  - 今日：ポップオーバーと同じ並び順
  - 予定：期日の近い順。同じ日なら優先度の高い順
  - 期日なし：優先度の高い順。同じなら作った順
- タスクの追加と編集（タイトル、期日、優先度、繰り返し設定、タイマー設定）、済んだ集中回数のリセット、アプリ設定ができる。
- ウィンドウを開いている間だけ、Dockと⌘Tabに出す。閉じたらメニューバーだけに戻り、アプリは終了しない。
- ランチャーからCatimerを起動すると、常駐していればウィンドウを開く。
- リサイズ、最大化、全画面表示に対応する。⌘+／⌘−で、アプリ全体の表示を拡大・縮小できる。

## MVPの後に回すもの

- 振り返り（作業時間の推移、集中しきれた割合）
- 完了したタスクを一覧で振り返る表示
- 期日による通知（リマインド）
- タスクのメモ、ドラッグでの並べ替え
- 「毎月◯日」「N日ごと」の繰り返し
- タイマー設定のプリセット
- グローバルショートカット（使う中で必要だと感じたものを、そのつど足す）
- 開始直後の取り消し（誤操作が多かったら検討する）
- 「今日」が切り替わる時刻の設定

## 未定のこと

- TypeScriptの型をRustから生成するツール（tauri-specta か ts-rs か）。最初の実装issueで、そのときの状況を調べて決める。
- 猫のアニメーションをMVPに入れるか。実装してみて判断する。
- 情シスへの確認。貸与PCへ開発環境（Command Line Tools、Rust、Node.js）を入れること、自作アプリを使うことを、まだ正式に確認していない。
- 配布するとき、App Store Connectで名前を予約できるか。説明文で「Pomodoro」という語を使う場合の商標の扱い。
