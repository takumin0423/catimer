# TypeScriptの型はts-rsで生成し、invokeのラッパーは手で書く

IPCで受け渡す型は、ts-rsでRustからTypeScriptの型として生成する。`invoke`と`listen`を呼ぶラッパーは、`src/api.ts`に手で書く。このアプリは長く使い続けるので、依存の安定性を優先した。コマンドの数は少ないので、手書きでも負担は小さい。

## Considered Options

- **tauri-specta**：コマンドとイベントの型付きラッパーまで生成できる。ただし、2.0は2026年11月時点でもRC（rc.26）のままで、14か月更新が止まっていた時期もある。RCごとに互換性が壊れるので、`=`で厳密に固定する必要がある。Tauri 3が出たときの追従時期も読めない。
- **taurpc**：specta上の型付きRPC。小さなプロジェクトで、specta のRCに固定されている。

## Consequences

- ts-rsは、i64を既定で`bigint`に変換する。一方、serde_jsonは数値として送る。そのため、i64のフィールドには`#[ts(type = "number")]`を付けて合わせる。
- コマンドの引数名や戻り値の型を変えたときに、手書きのラッパーが追従しているかは、コンパイラが検査しない。
