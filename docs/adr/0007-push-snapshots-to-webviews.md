# Webviewへは状態のスナップショットを送り、TanStack Queryは使わない

状態を持つのはRustだけにする。Rustは、状態が変わるたびにスナップショットを丸ごとイベントで全Webviewに送る。フロントは起動時に1回だけ`invoke`で取得し、あとはイベントを`useSyncExternalStore`で購読して描画する。更新はすべて`invoke`で、その結果も同じスナップショットで返ってくる。

TanStack Queryを使う案も検討した。しかし、ポップオーバーとウィンドウはJavaScriptの実行環境が別々なので、キャッシュが2つになる。そうなると、Rustの状態と合わせて3か所の整合を、無効化と取り直しで保つことになる。一方、送るデータは数KB程度で、毎回丸ごと送っても問題ない。そのため、データを一方向に流すだけの単純な方式を選んだ。この方式は、ADR-0001の「Webviewは描画だけ」とも素直に噛み合う。

残り時間は、ADR-0002のとおり、フロントで終了予定時刻から計算する。そのため、毎秒のイベントは送らない。
