# メニューバーの猫

メニューバーに出すドット絵の猫について、見た目の方向性と、試して決めたことをまとめる。仕様（いつどの状態を出すか）は [concept.md](./concept.md) の「メニューバー」にある。

叩き台は Claude Artifact で作った（https://claude.ai/artifact/4N5EYLdqFhZHBnAnDreht7 、非公開）。下のドット絵は、その叩き台と同じデータ。

## 方向性

- **可愛さを最優先にする。** 頭の大きいちびキャラ体型にする。頭が全体の高さの約6割、体は小さく丸い。
- **顔で可愛さを出す。** 目は縦長の丸で、間を広めに空ける。鼻とほっぺは半透明で入れる。耳は丸みのある三角。
- **どの状態も同じ頭を使う。** ポーズが変わっても、同じ猫に見えるようにする。
- **動きは控えめにする。** 集中を邪魔しないよう、視界の端で大きく動かない。

## 試してやめたこと

| 案 | やめた理由 |
|---|---|
| 集中中に猫が走る | 動きが大きく、しっくりこなかった |
| 正面を向いて手を上げる（招き猫、手を振るなど） | 上げ方に違和感があり、丸くしても可愛くならなかった |
| 実物に近い体つき（小さい頭、つり目、陰影） | 凝ってはいるが、可愛さが消えた |

## 絵の決まりごと

- サイズは横22×縦18ドット。どの状態も同じ幅にして、状態が変わってもメニューバーの幅が変わらないようにする。
- テンプレート画像として描く（白黒と透明度だけ）。色は macOS が付けるので、ライト・ダーク用に描き分けない。
- 下の図では、`#` が塗り、`o` が半透明（約60%）、`+` が薄い半透明（約40%）、`.` が透明。

## 状態ごとのポーズと動き

| 状態 | ポーズ | 動き |
|---|---|---|
| 待機 | 香箱座り | なし（静止画） |
| 集中 | 正面を向いて座る | しっぽが左右にゆっくり揺れる |
| 休憩 | 目を閉じて香箱座り | 寝息に合わせて頭が上下し、Z が浮かんで消える |
| 完了 | にっこり目（^ ^）で座り、両側にキラキラ | なし（静止画） |

### 休憩

寝息は、頭の高さが違う2枚（吸う・吐く）で表す。Z は耳の横から浮かび、大きくなって薄れて消える。0.5秒ごとに8コマを回し、1周は約4秒。

| コマ | 頭 | Z |
|---|---|---|
| 1–2 | 吸う | 小さい z（下） |
| 3–4 | 吸う | 小さい z（上） |
| 5–6 | 吐く | 大きい Z |
| 7 | 吐く | 大きい Z（薄く） |
| 8 | 吐く | なし |

## 実装メモ

- トレイアイコンは `TrayIcon::set_icon` で差し替える。動きは、残り時間の表示（毎秒の `set_title`）と同じ更新ループで、フレームを切り替えて作る。
- アイコンを差し替えたときに、テンプレート画像の扱いが外れないか確かめる。外れると、ダークモードで黒い猫のまま表示される。
- 画像は、集中3枚、休憩は寝息2枚と Z を組み合わせた8枚、待機1枚、完了1枚。
